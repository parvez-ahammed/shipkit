Open-source plugin for Claude Code

Claude Code skills that review, fix, test and ship your code

ShipKit is a free, open-source plugin for Claude Code that adds 24 skills and 2 git hooks. The skills review branches, fix bugs from the root cause, test the running app, audit QA and UX, guide refactoring, deploy to a VPS, add an MCP server for Claude and ChatGPT, improve SEO and write videos, demos and user guides. It works on any stack, on Windows, macOS and Linux.

How do I install ShipKit?

Run these two commands inside Claude Code.

/plugin marketplace add parvez-ahammed/shipkit
/plugin install shipkit@shipkit
  1. Add the marketplace: /plugin marketplace add parvez-ahammed/shipkit
  2. Install the plugin: /plugin install shipkit@shipkit
  3. Ask for what you need in plain words, or run a skill directly, for example /shipkit:review-branch.

What skills are in ShipKit?

24 skills in seven groups. Each card shows the slash command. Select a name to read its SKILL.md on GitHub.

Review and fix

  • review-branch

    Multi-seat code review of a branch or PR: backend, frontend, architecture, tests, QA and text seats. Every finding survives a refutation pass; you get one ranked punch list and an HTML report.

    /shipkit:review-branch

  • fix-bug

    One bug end to end: reproduce, prove the root cause before any fix, write a regression test that fails without the fix, verify.

    /shipkit:fix-bug

  • build-story

    One user story or ticket from raw ask to review-ready code: skeptical requirement analysis, task breakdown, implement, test, verify.

    /shipkit:build-story

  • test-branch

    Tests a branch against the real running app, not the diff: seeds data, drives the API and browser, and writes an HTML report with screenshots.

    /shipkit:test-branch

  • grill-feature

    Interrogates shipped features at the promise level and answers from the code with file:line evidence.

    /shipkit:grill-feature

Plan and deliver

  • groom-issue

    Scores a ticket's readiness against a rubric, finds gaps and undeclared blockers, and rewrites it into a buildable plan only after you confirm. Brief mode gives an executive brief of a milestone in build order.

    /shipkit:groom-issue

  • deliver-issue

    Delivers one issue or a whole milestone end to end: groom, plan, build, review, test, ship. Pushing, PRs and merges wait for your yes.

    /shipkit:deliver-issue

  • price-product

    Pricing tiers, margin-safety per tier, competitor prices with cited sources, value metric, and a check of every price surface for contradictions.

    /shipkit:price-product

QA and UX

  • audit-app

    Pressure-tests a running web app: a QA release report and a six-persona UX audit, as two cross-linked HTML reports with screenshot evidence.

    /shipkit:audit-app

  • find-ux-gaps

    Parallel read-only UX auditors triage findings into evidence-backed tickets, filed to GitHub, GitLab, Jira or Azure DevOps only after you confirm.

    /shipkit:find-ux-gaps

Refactor and architecture

  • refactor

    Finds the 22 classic code smells, gives Martin Fowler's safe refactoring mechanics, and scores creational, structural and behavioral design patterns against your code: APPLY, CONSIDER or REJECT with evidence.

    /shipkit:refactor

  • enforce-clean-architecture

    Clean / Hexagonal architecture rulebook, bootstrap for .NET, TypeScript, Java, Go and Python, and a layering guard.

    /shipkit:enforce-clean-architecture

  • find-shared-code

    Finds what is worth sharing across a backlog with DRY, KISS and YAGNI judgment, and what to resist abstracting.

    /shipkit:find-shared-code

  • simplify-code

    Removes over-engineering in one behavior-preserving change set: dead code, needless layers, reinvented helpers. Verified by your own build and tests.

    /shipkit:simplify-code

  • trim-comments

    Deletes comments that restate the code or narrate history and keeps the ones that explain a non-obvious why. Comment-only, gate-verified.

    /shipkit:trim-comments

Ship and operate

  • deploy-to-vps

    Push-to-deploy CI/CD for a containerized app to a VPS: GitHub Actions, Caddy automatic HTTPS, DNS, OAuth redirects, baseline hardening and health checks that report real readiness.

    /shipkit:deploy-to-vps

  • add-mcp-server

    Adds an MCP server to your app so its owner can ask Claude or ChatGPT about their own data: read-only tools on your own report queries, scoped API keys and OAuth 2.1 sign-in.

    /shipkit:add-mcp-server

  • boost-seo

    SEO and AEO audit and fixes: meta tags, JSON-LD, robots.txt, sitemap, llms.txt and SPA prerendering, proven with local tests.

    /shipkit:boost-seo

Create and document

  • make-video

    Promo, explainer and social videos built entirely from code, rendered to MP4 with voice-over, music, captions and a thumbnail.

    /shipkit:make-video

  • make-demo

    Pixel-exact clickable HTML demo of a planned workflow, captured from your real running app.

    /shipkit:make-demo

  • write-user-guide

    End-user feature guide for a ticket or PR as HTML and PDF; a fresh agent checks every claim against the code.

    /shipkit:write-user-guide

  • write-plainly

    A plain-English house style for commits, PR descriptions, code comments and docs.

    /shipkit:write-plainly

Insight

  • show-usage

    Active time, sessions, tokens and cost per project, from your local Claude Code transcripts.

    /shipkit:show-usage

  • fill-timesheet

    Reconstructs what you worked on for past dates, as paste-ready timesheet rows.

    /shipkit:fill-timesheet

How does ShipKit work?

Every skill has a description that says when to use it. You can let Claude Code pick the skill, or pick it yourself.

It triggers on its own

Claude Code reads each skill's description. When your request matches, it loads that skill. Say "review my PR before I open it" and review-branch runs. Three skills run only as commands: deliver-issue, show-usage and fill-timesheet.

Or run it explicitly

Type the slash command to run one skill directly: /shipkit:<skill>, for example /shipkit:fix-bug.

What git hooks are included?

Two git hooks for checks that must run on every commit. Install them per repository; each hook's README has the steps.

  • secret-hygiene

    Blocks a commit that adds a secret. Uses gitleaks when it is installed, with a regex fallback.

  • safe-commit

    Commit-message validator: conventional subject, length and stray @ lines.

Frequently asked questions

What is a Claude Code skill?

A skill is a folder with a SKILL.md file, plus optional references and scripts, that teaches Claude Code how to do one kind of task. Claude Code reads the short description of each installed skill and loads the full instructions only when your request matches it.

Can I install only one skill?

Yes. Each skill is a self-contained folder. Copy plugins/shipkit/skills/<name> from the repository into ~/.claude/skills/<name> (or into .claude/skills/ inside a project) and restart Claude Code. A skill installed this way is invoked as /<name> instead of /shipkit:<name>.

Does ShipKit work on Windows?

Yes. ShipKit works on Windows, macOS and Linux. Where a helper script depends on the shell, there is a bash version and a PowerShell version.

Is ShipKit free?

Yes. ShipKit is free and open source under the MIT license. You need Claude Code itself to run the skills.

How do I contribute?

Open an issue or a pull request on the GitHub repository at github.com/parvez-ahammed/shipkit. Bug reports, fixes to existing skills and new skills are welcome.
